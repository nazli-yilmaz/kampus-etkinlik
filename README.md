# Kampüs Etkinlikleri

Üniversite öğrencilerinin kampüs etkinliklerini görüntüleyebildiği, arayabildiği ve etkinlikler hakkında detaylı bilgi alabildiği React tabanlı web uygulaması.

## Kullanılan Teknolojiler

- React
- TypeScript
- Vite
- React Router
- Context API
- CSS

## Kurulum

```bash
cd frontend
npm install
npm run dev
